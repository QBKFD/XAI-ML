# Original thesis notebooks

These are the notebooks the thesis results were produced with (spring 2024),
kept unchanged for reference. They read files from Google Colab and local
download folders, so they do not run as they are. Everything they did is now
in `src/xai_rules/` and `scripts/`; see the main README for how to rerun it
and for the problems that rerunning turned up.

| Notebook | Thesis section |
|---|---|
| `preprocessing.ipynb` | 3.1, discretisation and encoding of the datasets |
| `ruleopt.ipynb` | RuleOpt results and grid search (Tables 2 and 8) |
| `mdl.ipynb` | MDL results (Tables 2, 3 and 5) |
| `ids.ipynb` | IDS results and lambda tuning (Tables 3, 4, 6 and 7) |
| `corels.ipynb` | CORELS results (Table 2) |
| `baselines.ipynb` | Random Forest, CART and C4.5 (Tables 2 and 3) |
